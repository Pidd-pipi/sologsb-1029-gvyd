# 移动端语言听写练习工具（sologsb-1029）

面向手机使用的听写练习应用，包含学习端和教师反馈视图。课程、未提交答案、练习进度、逐词结果与反馈均保存在浏览器本地，可离线继续已下载课程。支持多学生档案：同一台平板轮流使用时，每位学生的进度、草稿、记录互不影响。

## 功能

- 学习档案：首次打开先填姓名建档，之后从首页顶部切换或新增学生；每个档案各自保存当前课节、当前句、每句草稿、练习记录和已分类错误，切换后立即对应当前学生。
- 课程库：按课程和课节展示难度、句数、预计时长与下载状态；下载标记全设备共用，下载一次所有学生都能练。
- 离线课程：可切换课节下载标记；首次访问后由 Service Worker 缓存应用壳，断网重开仍可进入已下载课程并继续编辑。
- 听写流程：调用浏览器语音合成播放完整句子，输入答案后按句导航或整课提交。
- 逐词判错：使用词级序列比对识别拼写、漏词和多余词，并生成单句与整课得分。
- 错误复核：错误词可单独重听；可选择起止词重听指定片段；可为每个错误选择类别并记录原因。
- 教师反馈：教师视图按学生筛选作答并写入反馈，反馈只写回被选中学生的档案，并回显在该学生的学习记录中。
- 进度恢复：保存每句答案和当前句，刷新、切换应用或手机旋转后可恢复。
- 可访问性：支持浅色/深色模式、五档字号区间、触控尺寸、键盘提交和减少动态效果偏好。
- 记录导出：将练习历史、逐词结果、错误分类、原因和教师反馈按学生分组导出为 JSON。

## 技术栈

- Vue 3
- TypeScript 5
- Varlet UI
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器监听 `0.0.0.0`，适合通过局域网在手机浏览器中测试。宿主机正式端口按根目录 `docker-compose.yml` 映射为 `10029:80`。

## 类型检查与生产构建

```bash
npm run typecheck
npm run build
npm run preview
```

生产文件输出到 `dist/`。

## Docker

```bash
docker build -t sologsb-1029 .
docker run --rm -p 10029:80 sologsb-1029
```

最终镜像仅包含 nginx 和静态构建产物，nginx 监听容器 `80`。

## 数据说明

浏览器存储键为 `sologsb-1029-dictation-state-v1`，当前为 schema v2：课程与下载标记全设备共用；练习记录、课节/句子位置、每句草稿按学生档案分开存储。从 v1 升级时，已有记录自动归入“默认学生”档案。导出文件为 UTF-8 JSON，按学生分组（`students[].attempts` / `students[].progress`），可用于后续学习分析。
